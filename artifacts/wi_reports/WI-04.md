# WI-04 — S_DET 정합 (수식 문서 + 3후보 추출 도구 + 이진vs등급 모드)

## 산출물
- (a) `audit/sdet_formula.md` — 8성분 가중합 실수식(코드 인용), 치명 0점 규칙, 임계 70 실측,
  논문 정의(1−구조 편집거리, 임계 0.8)와의 차이표 + FIX_PAPER 문구 제시.
- (b) `tools/extract_sdet_examples.py` — 동일 명령 3후보(S_DET 실값): row 1 실측
  cand_1 unknown_service **61.25 (fail)** / cand_2 schedule·numeric drift **85.00 (pass)** /
  cand_3 invalid_json **0.00 (치명)** → `audit/sdet_examples.json`.
  주목: cron·period 훼손 후보가 85점으로 통과 — 합성 점수 특성상 스케줄 오류 단독으로는
  임계 70을 뚫지 못함(논문 서술 시 참고).
- (c) 이진 vs 등급 적합도 모드: `--fitness-mode graded|binary` 실배선
  (기존 파싱만 되던 플래그를 fitness.py→engine→summary까지 연결, C-22).
  비교 러너 `tools/run_binary_vs_graded.py` → `results/search_signal/<ts>/binary_vs_graded.csv`
  (+summary: 예산 내 최고 DETPass, 도달 세대). 엔진 progress에 `best_det_pass_rate` 컬럼 추가.
