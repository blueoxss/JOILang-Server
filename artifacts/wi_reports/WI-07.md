# WI-07 — 적합도 5항 정리 + 가중치 config 외부화 + 층화 표본기

## STEP 1 SPEC
- 목적: C-07/C-08/C-09 해소 — 논문 5항 적합도(α·DETPass + β·S_DET + γ·ReplayFit − λt·Tok̂ − λl·Lat̂),
  가중치 0.50:0.15:0.20:0.10:0.05 config 외부화, 범주 층화 표본기.
- 변경 파일:
  - `configs/ga_search_fitness.json` (신규) — 가중치·정규화 기준(tokens_ref 4096, latency_ref 5.0s)
  - `utils/ga_search/fitness.py` (신규) — load_fitness_config / compute_fitness / aggregate_genome_scores
  - `utils/ga_search/rerank.py` — 하드코딩 수식 제거, fitness.py로 위임(하위호환 시그니처)
  - `utils/ga_search/dataset_runner.py` — stratified_sample_rows + select_dataset_rows(stratify_per_category)
  - `utils/ga_search/cli.py` — `--fitness-config`, `--stratify-per-category` 배선
  - `utils/ga_search/ga_engine.py` — fitness_config 전달 + ga_summary에 가중치 스냅샷 기록
  - `utils/ga_search/llm_backends.py` — `_usage` total_tokens 파생 버그 수정

## 설계 결정
- 모든 항 [0,1] 정규화: S_DET = det_score/100, Tok̂ = avg_total_tokens/tokens_ref(클립 1),
  Lat̂ = avg_latency/latency_ref(클립 1).
- ReplayFit 미배선(WI-05 전) 시 γ항 0 + `replay_fit_missing=true` 기록 — 값 날조 금지.
- gt_exact_rate는 보고용 지표로 유지하되 적합도 항에서 제외(논문 정합).

## STEP 5 DIAGNOSE (이번 WI에서 발견·수정한 원인)
1. `_usage(prompt, completion)` 호출 시 기본 인자 `total_tokens=0`이 명시값으로 취급되어
   `_int(0, prompt+completion)`이 fallback 대신 0을 반환 → worker 경로에서
   `generation_total_tokens_total`이 항상 0 (프로브 실측으로 확인). `total<=0 → prompt+completion` 파생으로 수정.
2. WI-01 감시 테스트가 rerank.py 수식 변경을 정확히 탐지 → manifest 생성기·테스트를
